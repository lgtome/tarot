# App Assets

This directory should contain the following assets for the Tarot Cards app:

1. `icon.png` - The app icon (1024x1024px recommended)
2. `splash.png` - The splash screen image (centered logo with transparent background)
3. `adaptive-icon.png` - Android adaptive icon foreground layer
4. `favicon.png` - Web favicon

## Design Guidelines

For best results, follow these guidelines:

- **Color Scheme**: Use dark green (#0A2E0A) and gold (#F9E79F) as the primary colors
- **App Icon**: Should feature a stylized tarot card or mystical symbol in gold on a dark green background
- **Splash Screen**: The app name "TAROT CARDS" in gold serif font on a dark background
- **Visual Style**: Mystical, elegant with decorative elements like stars and flourishes

## Image Requirements

- **icon.png**: 1024x1024px, PNG format with transparency
- **splash.png**: 1242x2436px (centered design with plenty of padding)
- **adaptive-icon.png**: 1024x1024px foreground layer
- **favicon.png**: 196x196px
